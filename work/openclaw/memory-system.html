OpenClaw Memory Architecture

How the new memory layer finds the right context.

Mini 1 now has a deterministic ConfigGraph beside the existing QMD text memory system. The point is simple: parse operational truth from live config and state, retrieve prose only where it helps, then let the active agent model explain the retrieved evidence.

What changed

1. Config facts became queryable

openclaw-kg parses Mini 1 config and state into typed nodes and edges: agents, workspaces, models, providers, cron jobs, sessions, docs, tools, and delivery targets.

2. Text memory stayed text memory

QMD still handles MEMORY.md, daily notes, project files, and KB prose with BM25, vector search, and reranking. It remains the layer for history and rationale.

3. The active model explains evidence

The model gets a retrieved neighborhood: parsed facts, source paths, and relevant docs. It summarizes after retrieval instead of inventing the operational graph.

How a question moves through it

Question

"Why is steiPete using this model?"

Graph neighborhood

openclaw-kg agent steipete, openclaw-kg agent forge-sonnet, or a model query returns agent, model, fallback, workspace, doc, and cron relationships.

Answer

The active agent model receives the graph facts plus project notes, then explains the current routing and the reason it differs from stale memory.

Forge and Sonnet use the same system.

If the session is Forge or Forge (Sonnet), synthesis is handled by anthropic/claude-sonnet-5. ConfigGraph and QMD still do the retrieval work; Sonnet just becomes the reasoning layer that explains the evidence.

Trust model

Highest trust

  • ~/.openclaw/openclaw.json
  • ~/.openclaw/state/openclaw.sqlite
  • Current project files and KB docs

Derived, rebuildable

  • ~/.openclaw/state/openclaw-kg.sqlite
  • ConfigGraph nodes and edges
  • Stale checks and trace output

Lower trust

  • Old session transcripts
  • Abandoned plans
  • Memory snippets not yet reconciled to project docs

Current Mini 1 commands

Summarize the graph

openclaw-kg summary --refresh

Trace relationships

openclaw-kg trace agent steipete

Find operational drift

openclaw-kg stale
