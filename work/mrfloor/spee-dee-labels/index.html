How to review and quote Spee Dee-eligible orders, create one authorized live shipment, build a selected-label 2-up PDF, save it for Debbie, and correct mistakes without creating another shipment.

1. Open The Plugin

  1. Log in to WordPress admin. Use production for live work, staging for tests only.
  2. Open the plugin page. Go to WooCommerce > Spee Dee Labels.
  3. Ignore the license mismatch banner. That banner belongs to another plugin and does not affect Spee Dee labels.
Production URL: https://www.mrfloor.com/wp-admin/admin.php?page=mrfloor-speedee-labels
Staging URL: https://mrfloor23stg.wpenginepowered.com/wp-admin/admin.php?page=mrfloor-speedee-labels

2. Confirm The Operating Mode

  1. Open Settings before any create action. Do not assume the mode from an old screenshot or a prior shift.
  2. Current production mode (verified September 25): Dry-run mode is unchecked and Shipment creation is checked. That is live mode.
  3. Current staging mode: Dry-run mode is checked and Shipment creation is unchecked. Use staging for safe test work.
  4. Leave carrier fields alone. The tested default is Label with viewer ID a420e67552e.
Do not toggle production settings as a troubleshooting step. If live mode is not intended for the work in front of you, stop and get direction; use staging for a test instead.

3. Quote Or Find An Order

  1. Use Ready for new orders. Click Check Spee Dee when the button appears.
  2. A successful quote returns to Ready. The confirmation says the order is in Print Queue, so you can keep reviewing Ready orders without using Back.
  3. If you see View Queue, the order is already quoted. Open the Print Queue when you are ready to review it.
  4. Read the Packages column; do not hand-edit it. The plugin converts cleaner orders into Debbie's approved cartons. Replacement mop-pad-only orders are intentionally blocked for USPS bubble-pack handling, not forced into Spee Dee.
  5. Out-of-service states are blocked. GA/TN and similar rows should go to Needs Attention instead of calling Spee Dee.
A quote does not create a shipment, label, customer email, or carrier charge. It only checks price/service and stores the order in the local plugin queue.

4. Create One Shipment

  1. Confirm you have authorization. Production is currently live. Do not use its enabled state as permission to create a shipment.
  2. Open Print Queue and select exactly one eligible quoted order. The same checkboxes are used for creation and batching, so confirm the one selected row before continuing.
  3. Click Create Spee Dee shipments for selected. Wait for the page to return to the queue; do not click again.
  4. Confirm Label ready. The row should show a shipment/tracking value and a Download label link, which opens the stored PDF in a new tab.
  5. Check the Woo order tracking card. The plugin writes Spee-Dee Delivery, the tracking value (an SD... shipment ID is used if no barcode is returned), and the customer tracking-portal link.
  6. If the shipment exists but the PDF is missing, use Fetch label. It retries label retrieval only; it does not create a second shipment.
Creation is a real external API call to Dispatch Science and is the charge-risk action. Use one selected order until the workflow is fully approved.

5. Generate And Save The 2-Up PDF

  1. Stay on Print Queue and select only Label ready rows. Quoted rows do not have labels. The plugin fails closed if any selected row is not label-ready.
  2. Choose 2-up letter and a Start slot. Use Top for a new sheet or Bottom if the top half has already been used.
  3. Click Generate 2-up batch PDF. Open the Batches tab and download the latest batch. The link opens in a new tab and changes to Opening….
  4. Use the generated filename. It is automatically named speedee-batch-YYYY-MM-DD-01.pdf; the last two digits advance for each local WordPress day.
  5. Save the downloaded PDF to Dropbox. Use /Dropbox/Mr. Floor/Spee Dee Delivery.
  6. Debbie prints in Skokie. Print actual size on 8.5x11 half-sheet label stock, scale 100 percent, duplex off.
Downloading, saving, and printing the PDF does not create another Spee Dee charge. The charge-risk step is creating the shipment.
If you see No labels are ready to batch, the queue contains quotes only or created shipments whose PDFs were not stored. Create an approved shipment first, or use Fetch label for an existing shipment with no PDF.

6. Cancel Or Clear A Mistake

  1. Cancel shipment voids the external Dispatch Science order and removes the matching Spee-Dee Delivery tracking record from WooCommerce.
  2. Remove only removes the local plugin queue row. Use this for quoted rows or stale queue cleanup.
  3. Confirm the cancellation banner. Do not Remove a created row until the cancellation succeeds. If cancellation fails, leave the row in place and escalate it.
Do not use Remove as a substitute for Cancel after a shipment has been created. Production currently runs in live mode; do not change Settings merely to clean up a row.

Operator Checks

Live-state check At last verification, production was dry_run=0 / enable_create=1; staging was dry_run=1 / enable_create=0. Check Settings again before you act.
Quoted state Quoted rows have price only. They do not have shipment ID, tracking, or label file, and cannot be batched.
Label-ready state Created rows should show shipment/tracking and a Download label link before batching. Use Fetch label if the shipment exists but the PDF is missing.
If a row's state does not match this guide, treat the live WordPress UI as the immediate source of truth and stop before a create, batch, or cancel action. The plugin owner can inspect the queue and settings directly.
