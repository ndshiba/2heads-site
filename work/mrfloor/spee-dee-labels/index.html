Mr. Floor Shipping Labels Plugin Runbook

Use one WooCommerce tool to compare Spee Dee with Veeqo rates, deliberately create the chosen carrier label, then download or batch the stored PDFs. A rate shop is free. A label purchase is not.

Plugin version: v0.1.27 Spee Dee and Veeqo purchase enabled Default label: 4x6 Label Start: WordPress login > WooCommerce > Spee Dee Labels

Start-to-Finish Version

1. Sign InLog in to Mr. Floor WordPress with your assigned account.
2. Open the PluginWooCommerce, then Spee Dee Labels.
3. Shop RatesReady compares Spee Dee and Veeqo where applicable. This does not buy anything.
4. Choose One RateInspect the address, carrier, service, carton count, and total in Print Queue. Selection is still quote-only.
5. Purchase And Verify PDFsUse the carrier-specific action, then confirm a stored readable PDF exists for every physical carton.
6. Generate The BatchSelect the label-ready row and make the explicit 2-up print batch.
7. Resolve ExceptionsUse the carrier's void action for a created label. Do not remove evidence to hide a mistake.
Charge-risk actions: Create Spee Dee shipments for selected creates Spee Dee shipments. Purchase selected Veeqo label creates Veeqo carrier shipments and charges. Selecting or refreshing a rate does neither.

1. Sign In And Open Spee Dee Labels

  1. Open Mr. Floor WordPress. Go to https://www.mrfloor.com/wp-login.php and use your own assigned account.
  2. Open WooCommerce, then Spee Dee Labels. Do not start from the regular Orders list. The shipping workflow is inside the plugin.
  3. Start on Ready. The working tabs are Ready, Print Queue, Needs Attention, Batches, and Settings.
The direct page is https://www.mrfloor.com/wp-admin/admin.php?page=mrfloor-speedee-labels. Do not change Settings during ordinary fulfillment.

2. Shop Rates From Ready

  1. Check the order and packages. Confirm the recipient and destination. Do not hand-edit the cartons or weights. The plugin uses the approved product and carton data.
  2. For a Spee Dee service-area order, click Compare shipping rates. This queues a comparison that includes the Spee Dee quote and applicable Veeqo rates.
  3. For an out-of-area order, click Shop Veeqo rates. This queues Veeqo rates only.
  4. Open Print Queue with View rates or View Queue. A rate shop saves the comparison for review. It creates no shipment, label, tracking update, email, or carrier charge.
If a Veeqo quote is expired or the carton plan has changed, click Refresh rates before choosing a carrier. Do not try to use an old price.

3. Select The Carrier In Print Queue

  1. Confirm Ship to. Read the full name and address in the Print Queue before choosing a rate.
  2. Compare the visible carrier, service, delivery estimate, carton count, and total. The Veeqo total is the total for all physical cartons when more than one carton is shown.
  3. Select one rate only. Select Spee Dee $... converts the row to the normal Spee Dee quoted state. Select UPS $..., Select FedEx $..., or another Veeqo carrier records that Veeqo choice without buying it.
  4. Do not select tender-only services. The plugin blocks them from warehouse selection. If a desired service is unavailable, refresh rates or stop for review.
Select is not purchase. After selecting Veeqo, the row reads Selected: label purchase pending. That is the last safe review point before a carrier charge.

4. Create A Spee Dee Shipment

  1. Use this branch only after selecting Spee Dee. The row must be a regular Quoted: no label yet row, not Veeqo-selected.
  2. Select up to five approved quoted rows. Click Create Spee Dee shipments for selected once. The plugin prepares them one at a time.
  3. Wait for completion. Do not refresh or click again while the page shows Preparing order.
  4. Confirm each row becomes label-ready. A completed row has a shipment or tracking value and Download label. If the shipment exists but the PDF is missing, use Fetch label. That does not create a second shipment.
This is a real Dispatch Science and Spee Dee creation call. It may create a billable shipment. Do not use it to reprint an older label.

5. Purchase A Selected Veeqo Label

  1. Use this branch only after selecting a current Veeqo rate. Re-read the carrier, service, total, and carton count in Print Queue.
  2. Click Purchase selected Veeqo label. The button may say plural labels for a multi-carton shipment. Confirm the browser prompt only if the displayed carrier, service, carton count, and amount are correct.
  3. Wait for the recorded result. Do not double-click or refresh while purchase is in progress. The plugin locks the row against duplicate purchase clicks.
  4. Confirm Veeqo label ready to batch and stored PDFs. Every physical carton receives its own purchased label. This status appears only after every carton PDF has been stored and is readable. The queue then allows individual download or 2-up batching.
Do not expect a label from selection alone. Veeqo purchase creates real carrier shipment(s) and charge(s), but it does not auto-generate the print batch. If any carton PDF is missing, unreadable, or the carrier returns an incomplete set, the row stops in Needs Attention. Do not repurchase to chase a label; preserve the row and resolve it first.

6. Download Or Batch Stored Labels

  1. Select only label-ready rows. Use Label ready to batch for Spee Dee or Veeqo label ready to batch for Veeqo. Quotes, selected-but-unpurchased rows, and attention rows cannot print.
  2. Use Download label for one order or reprint. It opens the stored carrier PDF. It does not create another shipment or charge.
  3. Use Generate 2-up batch PDF for a print run. This is the explicit Veeqo print step after purchase, exactly as it is for Spee Dee. Pick Top for a fresh half-sheet label page or Bottom if the top half is already used.
  4. Print every label page. The batch includes one page for each physical label, not merely one page per order. Save the generated PDF to /Dropbox/Mr. Floor/Spee Dee Delivery.
Print actual size on 8.5x11 half-sheet label stock at 100 percent, with duplex off. The filename is speedee-batch-YYYY-MM-DD-01.pdf; the sequence advances automatically.

7. Fix A Mistake Without Losing Evidence

  1. Expired rate or changed carton plan: use Refresh rates, then select again. Do not purchase a stale quote.
  2. Spee Dee shipment created by mistake: use Cancel shipment and wait for a successful cancellation before removing the local row.
  3. Veeqo label created by mistake: use Void Veeqo label. It submits a carrier void and refund request. Carrier refund eligibility controls the outcome.
  4. Partial purchase, missing stored PDF, or Needs Attention: stop. Do not remove the row, repurchase, or assume the carrier charge failed. The queue preserves the evidence needed to resolve it.
  5. Remove: clears only the local queue row. It never cancels or refunds a carrier shipment.
Never use Remove as a substitute for canceling or voiding a real carrier label.

Operator Checks

Quote only Rates are visible, but no label, tracking value, customer notification, or carrier charge exists.
Veeqo selected The carrier and price are locked for review. There are no labels yet. Purchase is still pending and remains a separate click.
Veeqo label ready to batch Every purchased Veeqo carton has a stored, readable PDF. Select the row, then explicitly generate the 2-up batch without another carrier charge.
Needs Attention Stop. Preserve the row and resolve the displayed issue before another carrier action.
